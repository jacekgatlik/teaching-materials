# Teaching materials

## Efficient Python CERN STEAM Academy

Efficient Python is a practice-oriented course on building reliable, readable, and high-performance workflows for scientific computing. It begins by treating vectors, matrices, and tensors as computational array objects, with particular emphasis on shapes, axes, indexing, broadcasting, and memory-aware operations. Participants then learn how to turn arrays into inspectable numerical experiments using NumPy and Matplotlib, and explore the numerical foundations of machine-learning workflows, including data organization, model fitting, losses, gradients, scaling, stability, and validation.

The course then moves from individual calculations to maintainable programs and reproducible data pipelines, covering explicit data flow, function interfaces, project organization, robust file handling, and labelled analysis with pandas. Its final part develops a disciplined approach to performance: benchmark first, locate bottlenecks through profiling and memory inspection, and only then select an appropriate acceleration strategy. Topics include algorithmic improvement, vectorization, memory control, selective JIT compilation with Numba, and concurrent or parallel execution. Throughout the course, scientific correctness, transparency, and reproducibility remain as important as speed.

### Repository structure

* `Lecture-notes/` contains slides and additional materials discussed during lectures.
* `Examples-for-lectures/` contains examples linked directly from the lecture notes.
* `Practical-sessions/` contains notebooks and files for hands-on exercises.

## Python (Język Python)

**This course is taught in Polish.**

Python Programming introduces the Python language and its applications in scientific computing and data analysis. The course begins with syntax, built-in data structures, control flow, and functions, then develops these foundations through modules, exception handling, file processing, and object-oriented programming. Students learn how to organize programs and work with data stored in formats such as CSV and JSON.

The course then moves to numerical computing with NumPy and SciPy, data analysis with pandas, and visualization with Matplotlib. It also introduces performance measurement, profiling, vectorization, and memory-aware programming. The final part explores the basics of machine learning and neural networks, including data preparation, model training, and evaluation. Practical exercises connect programming concepts with computational and data analysis tasks.

### Course directory structure

* `Lecture_notes/` contains lecture materials and supplementary notes.
* `Classes_materials/` contains exercises and assignments for laboratory classes.

## Introduction to Unix Systems

Introduction to Unix Systems is a practice-oriented course on using Unix-like operating systems in scientific and technical computing. It introduces the command-line environment, filesystem navigation, file management, permissions, and process control. Students learn how to combine standard Unix tools through redirection and pipelines, search and transform text with regular expressions, and automate everyday tasks using shell scripts.

The course also covers working with remote systems through SSH, transferring and synchronizing files, and using remote servers and computing clusters. Git, basic system administration, and an introduction to containers and isolated environments provide a foundation for organizing reproducible computational workflows. Throughout the course, the emphasis is on developing practical skills that transfer between local machines and remote computing environments.

### Course directory structure

* `Lecture_notes/` contains lecture materials and supplementary notes.
* `Classes_materials/` contains exercises and assignments for laboratory classes.
